# Расписание Гимназии №19

Веб-интерфейс для просмотра расписания, подготовленного в программе «Ректор». Сайт показывает расписание по классам, учителям и кабинетам, корректно разделяет несколько кабинетов в одном уроке и автоматически обновляется после изменения файла `Расписание.rtt`.

Рабочая версия: [rasp.gymn19.ru](https://rasp.gymn19.ru)

## Состав проекта

- `site/` — статический веб-интерфейс без серверного фреймворка;
- `windows/Publish-Schedule.ps1` — экспорт трёх представлений из «Ректора» и атомарная отправка на сервер;
- `windows/Install-Publisher.ps1` — установка ключа, фонового задания и ярлыка ручной публикации;
- `server/upload-api/upload_api.py` — защищённая очередь файлов `.rtt`;
- `server/install.sh` — первичная установка на Debian-сервере;
- `docker-compose.yml` и `nginx.conf` — запуск сайта в Docker;
- `server/rasp.gymn19.ru.conf` — обратный прокси и HTTPS для Nginx Proxy Manager;
- `server/rasp-cert-renew.*` — автоматическое продление сертификата Let's Encrypt.

Файлы актуального расписания в Git не сохраняются: экспорт может содержать имена сотрудников и локальные пути Windows. Они публикуются напрямую с рабочего компьютера на сервер.

## Запуск сайта

1. Скопируйте `.env.example` в `.env` и укажите адрес, на котором контейнер должен принимать соединения.
2. Поместите HTML-экспорт «Ректора» в `site/data/`.
3. Запустите:

```bash
docker compose up -d
```

По умолчанию сайт доступен на порту `8085`. Проверка состояния контейнера обращается к `/healthz`.

## Автоматическое обновление

Сценарий `Publish-Schedule.ps1` проверяет хеш файла `Расписание.rtt`. При изменении он:

1. открывает копию файла в программе «Ректор»;
2. экспортирует расписание классов, учителей и кабинетов;
3. создаёт архив новой версии;
4. передаёт его по SSH;
5. атомарно переключает сайт на новый выпуск.

На сайте также доступна кнопка **«Загрузить расписание»**. Пользователь выбирает файл `.rtt` и вводит пароль загрузки. Сервер проверяет размер и сигнатуру файла, после чего установленный на Windows издатель забирает его из очереди, выполняет экспорт через «Ректор» и сообщает странице об успешной публикации. Обычно обновление занимает одну–две минуты.

Для установки издателя рядом с `Install-Publisher.ps1` должен находиться приватный ключ `schedule_publisher_ed25519`. Ключ намеренно исключён из Git.

## Безопасность

- контейнер можно привязать только к внутреннему адресу;
- внешний доступ проходит через Nginx Proxy Manager;
- HTTP перенаправляется на HTTPS;
- сертификат Let's Encrypt проверяется и продлевается системным таймером;
- SSH-ключ издателя имеет отдельную учётную запись и используется только для загрузки новых выпусков.
- пароль загрузки и токен Windows-издателя хранятся вне Git в `.env` и `C:\ProgramData\Gymn19Schedule\upload-token.txt`;
- загружаются только файлы `.rtt` размером до 8 МБ с ожидаемой сигнатурой формата «Ректора».

## Версии

Текущая версия хранится в файле `VERSION`. Каждое изменение проекта оформляется отдельным Git-коммитом, а готовые версии отмечаются тегами `vX.Y.Z` и описываются в `CHANGELOG.md`. На сайте версия отображается как `Версия rasp.gymn 1.1.0`.
