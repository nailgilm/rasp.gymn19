Загрузить расписание

Подготовьте три HTML-экспорта в «Ректоре»:
  1. расписание по классам;
  2. расписание по учителям;
  3. расписание по кабинетам.

В каждом поле выберите сразу все файлы index*.html из соответствующей папки: основной index.html и все нумерованные страницы index0.html, index1.html…. Количество нумерованных страниц может отличаться.
