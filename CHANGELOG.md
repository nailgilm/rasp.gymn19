# Журнал изменений

Все заметные изменения проекта фиксируются отдельным Git-коммитом. Готовые версии отмечаются тегами `vX.Y.Z`.

## 2.2.4 — 2026-10-03

- в расписании классов учитель и его кабинет теперь выводятся одной связанной строкой;
- совместные и разделённые уроки показывают отдельную пару «учитель → кабинет» для каждого преподавателя;
- при замене сохраняется кабинет отсутствующего учителя.

## 2.2.3 — 2026-10-03

- к основным кнопкам расписания добавлены понятные эмодзи: классы, учителя, кабинеты, выбор недели, свободные кабинеты, обновление и админ-панель.

## 2.2.2 — 2026-10-03

- даты текущей недели теперь вычисляются по московскому времени;
- открытая страница автоматически перестраивает даты в течение минуты после смены дня и сразу после возврата на вкладку;
- в разделе замен добавлен поиск отсутствующего учителя и отдельный поиск кандидата в каждой строке плана;
- в репозиторий добавлена отдельная инструкция администратора по загрузке расписания, созданию и удалению замен, конфликтам и частым ошибкам.

## 2.2.1 — 2026-10-03

- выбор периода оформлен компактной кнопкой «Вся неделя» с выпадающим меню дней;
- недельное расписание перестроено в общую сетку: одинаковые номера уроков теперь находятся на одной горизонтальной линии;
- номер, время, предмет, учителя и кабинеты получили единое выравнивание внутри карточек;
- пустые части разделённых предметов и кабинетов больше не создают лишние символы и отступы.

## 2.2.0 — 2026-10-03

- замены формируются по точным календарным датам, а не только по дням недели;
- для каждого урока автоматически подставляются номер и фиксированное время звонка;
- подбор сначала предлагает свободного учителя предмета, затем свободного учителя этого класса;
- проверяются собственные уроки, другие замены, периоды отсутствия и повторные назначения в один временной слот;
- при отсутствии приоритетного кандидата показывается предупреждение и доступен ручной выбор другого свободного учителя;
- результат подбора показывается таблицей и сохраняется только после подтверждения всего плана;
- административные функции перенесены в отдельную панель с одной авторизацией на восьмичасовую сессию;
- выбор дня заменён компактным выпадающим списком «Вся неделя»;
- время урока отображается в дневном и недельном расписании, поиске свободных кабинетов и заменах.

## 2.1.2 — 2026-10-03

- добавлен поиск и защищённое паролем назначение замены отсутствующему учителю среди свободных преподавателей выбранного класса;
- дополнительно предлагаются свободные преподаватели того же предмета из других классов;
- добавлен период отсутствия: автоматический подбор составляет план на все уроки учителя между указанными датами;
- при автоматическом подборе приоритет получают свободные преподаватели того же предмета, а нагрузка распределяется между кандидатами;
- весь проверенный план можно применить одной защищённой паролем кнопкой;
- назначенная замена отображается в расписании класса, отсутствующего и заменяющего учителя;
- добавлена возможность снять ранее назначенную замену;
- добавлен поиск свободных кабинетов по дню и номеру урока;
- инструменты вынесены в две отдельные кнопки.

## 2.1.1 — 2026-10-03

- недельное расписание перестроено в компактные горизонтальные колонки;
- на широком экране вся учебная неделя помещается в одну строку;
- на узком экране недельную сетку можно прокручивать горизонтально.

## 2.1.0 — 2026-10-03

- перед днями недели добавлена кнопка «Вся неделя»;
- недельное расписание разбито на понятные блоки по дням;
- режим доступен для классов, учителей и кабинетов;
- для всей недели показывается общее количество уроков.

## 2.0.0 — 2026-10-03

- загрузка исходного файла `.rtt` заменена ручной публикацией готовых HTML-экспортов «Ректора»;
- форма принимает отдельные комплекты файлов для классов, учителей и кабинетов;
- перед публикацией проверяются имена, комплектность и структура HTML-файлов;
- текущая версия расписания автоматически архивируется перед заменой;
- фоновая проверка файла «Ректора» на рабочем компьютере больше не требуется.

## 1.2.0 — 2026-10-03

- в расписании классов добавлены фамилии учителей из раздела «Учителя»;
- совместные и разделённые уроки показывают каждого учителя отдельной меткой;
- пропущенные номера уроков больше не исчезают: внутри учебного дня они отображаются строкой «Нет урока»;
- пустые строки после последнего урока по-прежнему скрываются.

## 1.1.1 — 2026-10-03

- исправлено время обновления после ручной загрузки: файл из веб-формы теперь всегда публикуется заново, даже если его содержимое совпадает с текущим расписанием.

## 1.1.0 — 2026-10-03

- добавлена защищённая загрузка файла `Расписание.rtt` через сайт;
- добавлена серверная очередь с проверкой расширения, сигнатуры и размера файла;
- Windows-издатель автоматически забирает загруженный файл, экспортирует классы, учителей и кабинеты через «Ректор» и сообщает результат сайту;
- период проверки сокращён до одной минуты;
- версия интерфейса обновлена до `rasp.gymn 1.1.0`.

## 1.0.0 — 2026-10-03

- опубликован сайт расписания по классам, учителям и кабинетам;
- добавлена автоматическая публикация изменений из программы «Ректор»;
- настроены Docker, Nginx Proxy Manager и HTTPS;
- добавлена ссылка на портфолио разработчика NG;
- добавлена публичная ссылка на GitHub и полное обозначение версии `rasp.gymn 1.0.0`;
- текущая версия интерфейса закреплена как 1.0.
